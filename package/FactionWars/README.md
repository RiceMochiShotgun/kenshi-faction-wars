Contents of `Kenshi/mods/FactionWars/` once built:

- `FactionWars.mod` (created in FCS; can hold no data)
- `RE_Kenshi.json` (this folder)
- `FactionWars.dll` (from the Release x64 build)
- `FactionWars/` (copied from `data/FactionWars/`)
- `user/FactionWars/` (empty; player overrides)

`tools/` will get a deploy script that assembles this.
